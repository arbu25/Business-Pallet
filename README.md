Данный проект представляет собой онлайн B2B маркетплейс оптовых закупок с возможностью реализации в нем логистики. 
Краткое описание: проект предоставляет возможность выставлять на продажу оптовые товары продавцов, а покупатель в
свою очередь может быстро зайти на сайт в котором будут находится все поставщики оптовых товаров и не затрачивая много 
времени на живой поиск оформить заказ с возможностью логистики.
Выполнялась работа в небольшой команде состоящей из аналитиков, дизайнеров, разработчиков, тестировщиков, а также руководителей проекта.
